What is programming?

In your head

  • To think about a problem in a structured way — like when you want to build a lego model.
  • To come up with a way to solve the problem.
  • To give an unambiguous and exhaustive description of the way to solve the problem.

On the computer

  • To write the code.

What is a program?

  • A long sequence of simple instructions in a controlled order.
x = 4
y = x + 1

Pedagogical choices and omissions

  • The Python programming language.
  • Only the necessary elements.
  • A “layer upon layer” approach.
  • Tailor-made lecture notes.
  • Focus on clear and structured thinking.
  • Maximal learning vs. realism in the exercises.
  • Programming has to be done (a lot) to be learned.

The Karate Kid (1984)

The key to success

  • Make sure you can “see the lego bricks”.
  • Do not skip material. It only holds the most necessary things, so all of it matters.
  • Make sure your understanding keeps up all the way.
  • The “easy stuff” must be read, understood and practised more thoroughly than it may seem to need.
  • Do not give each other solutions — give help to self-help.
  • Most important: keep an eye on whether you can find solutions yourself — or whether you can only recognise them when you are shown them.

My expectations of you

  • Learning by doing - and failing miserably
  • Ask — especially stupid questions are important (for many others than yourself)
  • Reason — guessing and remembering will not carry you through courses.
  • Be brave, experiment, try things out

  • There will be no answer sheets or solutions to the exercises

Avoid mistakes in the first place

  • Trust your sense of logic - and remember to use it.
  • Do not guess, think it through before you begin.
  • Think in “Lego bricks”.
  • Use “# print steps” when you are losing the overview.

Make it easy to find mistakes

  • Start small.
  • Make sure it keeps working.
  • Print the relevant variables every time you add a line of code, and check that the values are what you expect.
  • Test your code with several different values/data.
  • Know Python’s error messages (exceptions).

Error messages

  • SyntaxError: “grammatical mistakes”
  • IndentationError: meaningless indentation
  • TypeError: when you try to combine objects of different type
  • NameError: when you refer to a name you have not defined

def partition(x, i, j):
    pivot = x[i]
    k, h = i + 1, j - 1
    while k <= h:
        if x[k] <= pivot:
            k += 1
        elif x[k] > pivot:
            x[k], x[h] = x[h], x[k]
            h -= 1
    pivot, x[k - 1] = x[k - 1], pivot
    return k - 1
