What's inside your computer
Your computer
Kept Where your files live
Permanent

💾Hard disk

Your files — code, data, everything — live here, and stay here even when the computer is switched off. Saving a file writes it to the disk.

Permanent · synced

☁️iCloud / OneDrive

A copy of certain folders is kept online and synced across devices. Convenient — but sync can move, rename or briefly lock your files at surprising moments, so keep course work in a simple, known folder.

Temporary Where the work happens
Temporary

🧠Memory (RAM)

Holds whatever is running right now — the program and the values it is working on. Emptied the moment a program stops or the computer restarts. Nothing here is saved unless you write it to the disk.

The worker

⚙️CPU

Does the actual computing — one small step at a time, extremely fast. It only ever works on what is currently in memory.

Tool you drive

🐍Python — the interpreter

A program that reads your code file, holds it in memory, and tells the CPU what to do one instruction at a time. It is the translator between your .py file and the machine. You installed it with the course installer.

Tool you drive

⌨️The terminal

A place to type commands like python hello.py. It's the same tool in three costumes: the Terminal app (Mac), PowerShell (Windows), and the terminal built into VS Code — use whichever is in front of you.

Where you write — and the two ways to run Python
Your workspace

📝VS Code editor

Where you write code and save it to the disk. For this course it is your AI-free space — your own fingers and your own understanding do the work here.

Starts clean

📄A script

A .py file on disk. Run in the terminal, it goes top to bottom, then stops — and starts fresh every time, remembering nothing from before.

Remembers

📓A notebook cell

Run one cell at a time in a Python session that stays alive in memory and remembers earlier cells. Powered by IPython / Jupyter.

Bridge

🔁The sandbox-widget — a cell that pretends to be a script

Turns a single notebook cell into a small isolated script: it runs clean, start to finish, remembering nothing — just like python file.py — but without leaving the notebook. Use it to feel the difference between "a cell that remembers" and "a script that starts fresh," side by side.

The AI lives somewhere else — on purpose
🔒 copilot — in your web browser

Copilot Chat

It lives in your web browser, in a separate window from VS Code. You decide when to open it. Nothing flows automatically between the AI and your code — and that is the point.

✋ You carry things across by hand

Copy a question or a piece of code to the chat; read its answer, then type what you choose to keep back into your editor.

Walking over to the AI is a deliberate choice. Each exercise's badge tells you which role it may play today — from Explainer to Delegate.
