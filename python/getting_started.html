8  Getting started

This chapter will get your computer set up with what you need for the course. You need to read carefully and follow instructions to the letter. They are different on Mac and Windows so pick which kind of computer you have below:

  • Mac
  • Windows

1. Quit VS Code completely first if it is running.

2. Open a new Terminal window and run this command to download the course folder

curl https://munch-group.org/instructing-machines/instructing-machines.zip > ~/Downloads/instructing-machines.zip

3. Run this to unpack the student folder and put it in your home folder:

unzip -o ~/Downloads/instructing-machines.zip && mv ~/Downloads/instructing-machines ~/.

4. Navigate to the course folder

cd ~/instructing-machines

5. Run this to install Pixi

curl -fsSL https://pixi.sh/install.sh | SHELL="$(ps -o comm= -p $$ | sed 's/^-//')" sh

6. Run this to make sure you can use pixi from the terminal;

pixi run shell

7. Now quit that Terminal completely and open a new one.

8. Run this in the new terminal to make sure pixi is installed. If it is, it will print its version nr.

pixi --version

9. Run this to build the environment:

pixi clean ; pixi install

10. Finish the setup

pixi run check

11. Install the course tool

pixi global install -c conda-forge -c munch-group im-course-tools

1. Quit VS Code completely first if it is running.

2. Open a new PowerShell (Start menu → PowerShell) and run this command to download the course folder.

iwr -Uri "https://munch-group.org/instructing-machines/instructing-machines.zip" -OutFile "$env:USERPROFILE\Downloads\instructing-machines.zip"

3. Run this to unpack the student folder and put it in your home folder:

Expand-Archive -Path "$HOME\Downloads\instructing-machines.zip" -DestinationPath C:\

4. Navigate to the course folder

cd C:\instructing-machines

5. Run this to install Pixi

irm -useb https://pixi.sh/install.ps1 | iex

6. Run this to make sure you can use pixi from Powershell;

pixi run shell

7. Now quit that Powershell completely and open a new one.

8. Run this in the new Powershell to make sure pixi is installed. If it is, it will print its version nr.

pixi --version

9. Run this to build the environment:

pixi clean ; pixi install

10. Finish the setup

pixi run check

11. Install the course tool

pixi global install -c conda-forge -c munch-group im-course-tools
Note

If pixi install fails, it may be because you have antivirus software (other than Microsoft Defender) that blocks Pixi from downloading packages. Here are instructions for how do do this for: BitDefender, Norton, McAfee, Kaspersky.

The VScode editor

You will also need a text editor. A text editor is where you write your Python code. For this course, we will use Visual Studio Code — or VS Code for short. You can download it from code.visualstudio.com. If you open VS Code, you should see something like Figure 8.1.

You may wonder why we cannot use Word to create and edit files with programming code. The reason is that a text editor made for programming, such as VS Code, only saves the actual characters you type. So, unlike Word, it does not silently save all kinds of formatting, like margins, boldface text, headers, etc. With VS Code, what you type is exactly what is in the file when you save it. In addition, where Word is made for prose, VS Code is made for programming and has many features that will make your programming life easier.

1. If VS Code was already running, quit it completely and start it again before you go on. Not “close the window”, quit the application.

1. Open VS Code. The first time you start VS Code it greets you with a welcome screen that wants you to sign in. Nothing on this course needs an account, so click Continue without signing in.

2. Open the instructing-machines folder using File → Open Folder. The entire setup only works if you open the folder. If you just open any single file nothing will work.

3. Accept when prompted to trust and install recommended extensions. If asked to trust the folder/workspace, accept that too. If there is a blue button saying “Trust” at the bottom left, click that too.

Opening a folder in VS Code from the terminal

Once you have VS Code installed, there is an alternative way to open a folder directly from the terminal. In a terminal, cd into the course folder and then run code .. . means “the current folder”.

code .

On Windows this works straight away, but on a Mac you need to do the following to make the code command available. Close all your Terminal windows. In VS Code, press Cmd+Shift+P, type Shell Command: Install 'code' command in PATH, and press Enter.
