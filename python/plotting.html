48  Plotting

This chapter introduces plotting in notebooks. The main plotting library for Python is Matplotlib. You can see examples of plots on its gallery page. You can do all the plotting you will ever need using Matplotlib, but the Seaborn library, which builds on top of matplotlib makes it much easier to produce powerful visualizations. For inspiration, you can see some of the plots you can make on the gallery page page.

This chapter focuses on the ways data can be visualized rather on the code required to do so. We use the iplot interactive widget to generate Seaborn plots and to show the code needed to produce them yourself. For more detail on Seaborn, you can visit the tutorial.

Run this cell import the iplot function and to download the penguins dataframe alwo used in ?sec-pandas.

import vscodenb
from iplot_widget import iplot, iplot_settings
iplot_settings(theme={'palette': 'viridis'})

import seaborn as sns
data = sns.load_dataset('penguins')
data

You may wonder why the arguments to the sns.displot function are written as name=value rather than just the values.

In Python, you can pass values to a function in this way too. Such keyword arguments (often called named arguments) explicitly stating the parameter name and its value using the parameter_name = value syntax. This is useful for three reasons:

  • Order independence: Keyword arguments do not need to match the exact order of parameters defined in the function. This is useful if there are many in an order that hard to remember.
  • Readability: Code becomes self-documenting because the intent behind each value is explicitly labeled.
  • Selective defaults: If a function has multiple parameters with default values, you can override just one specific parameter without passing values for the others too.
