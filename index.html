Instructing Machines is a collection of lecture notes, slides, exercises, tutorials, and projects, which serve as course content for the 2026 version of the undergraduate course Bioinformatics at Aarhus University. The aim of this course is to learn how produce code that solves problems relevant to molecular biology. Having completed to course will be able to:

  • Read code the way the machine does.
  • Write Python code to solve small problems.
  • Decompose a problem into smaller sub-problems and implement these as testable functions.
  • Verify correctness of plausibly correct code written by an AI or someone else.
  • Choose an appropriate level of AI involvement for a given task.
  • Explain why an AI’s usefulness is bounded by what the student already knows and is able to verify.

This content was made for the Bioinformatics course at Aarhus University teaching undergraduates in Molecular Biology and Molecular Medicine. The whole thing is MIT licensed, so if you teach a similar course, feel free to fork it and make your own.

/ Kasper Munch

The AI

In this course we use Microsoft 365 Copilot AI. As a student at Aarhus University, you can use this free of charge if you choose “Work” on the landing page and then use your student credentials to log in. That being said, the course material is not made for use with any particular AI.
