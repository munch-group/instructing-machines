54  Project: Pairwise alignment

This chapter is about global pairwise alignment, and you will implement your own Needleman-Wunsch algorithm.

Your task is to find an optimal alignment of two sequences. If two such sequences are roughly 140 bases long, there are as many different ways to align them as there are atoms in the visible universe. Finding an optimal alignment among those \(10^{80}\) possibilities is hard, but implementing the Needleman-Wunsch algorithm will let you do it.

This project is meant to build your coding skills and strengthen your understanding of the Needleman-Wunsch algorithm. The better you understand the algorithm before you begin, the easier and more rewarding the project will be. So, re-read the book chapter about pairwise alignment and browse the lecture slides.

Begin by downloading the project. Open your instructing-machines folder in VS Code. Then open a terminal (Terminal > New Terminal from the top menu) and run this command:

pixi run get alignmentproject

That puts the alignmentproject project folder straight into the projects folder inside your course folder, beside your notebooks.

If that fails, you can always click “Download project” in the top right corner of the page. This downloads a zip file to your Downloads folder that you need to then unpack and move into the projects folder of your student folder yourself.

You write your code in the file called alignmentproject.py. In the terminal, navigate to the project folder and run your code in the usual way:

python alignmentproject.py

To test the functions as you complete each one, you use pytest to run the project test suite in test_alignmentproject.py using this command:

pytest test_alignmentproject.py

The project is split into two parts:

  1. Filling in a dynamic programming matrix.
  2. Reconstructing the optimal alignment by doing traceback through the dynamic programming matrix.

To help you along, alignmentproject.py already contains a function I wrote for you, so you can print your matrices as you fill them in.

The function is named print_matrix and takes three arguments:

  1. A list of lists of integers, representing a dynamic programming matrix.
  2. A string, which represents a DNA sequence of some length m.
  3. A string, which represents a DNA sequence of some length n.

The function returns:

  • None, but it prints a nice representation of the matrix lined with the bases of the two sequences.

Here it is:

def print_matrix(matrix, seq1, seq2):
    max_len = max(len(str(cell)) for row in matrix for cell in row)
    fmt = "{{:>{}}}".format(max_len+1)
    row_fmt = fmt * (len(matrix[0])+1) + '\n'
    mat_fmt = row_fmt *  (len(matrix)+1)
    seq1, seq2 = ' ' + seq1, ' ' + seq2
    lst = [' '] + list(seq2)
    for i in range(len(seq1)):
        lst.extend([seq1[i]] + list(map(str, matrix[i])))
    print(mat_fmt.format(*lst))

Prepare the matrices

Make an “empty” matrix

Start by making a list of lists (a matrix) with the right shape, filled with None values. We use the None values as placeholders, which you can later replace with scores. Think of it as an empty matrix you can fill with scores, just as we did in the lectures. If you want to align two sequences like AT and GAT, you want a matrix with three rows and four columns. The matrix must have one more row than the number of bases in sequence one and one more column than the number of bases in sequence two.

Write a function, empty_matrix, that takes two arguments

  1. An integer (which represents the length of sequence one + 1).
  2. An integer (which represents the length of sequence two + 1).

The function must return:

  • A list of lists. The number of sub-lists must be equal to the first integer argument. Each sublist must contain a number of None values equal to the second integer argument.

Example usage:

empty_matrix(3, 4)

returns a list with three lists each of length four:

[[None, None, None, None], [None, None, None, None], [None, None, None, None]]

Even though this is a list of lists, we can think of it as a three-by-four matrix:

[[None, None, None, None], 
 [None, None, None, None], 
 [None, None, None, None]]

You can use print_matrix to print the matrix with the sequence bases along the left and top margins. Printing an “empty” matrix will look like this:

          G    A    T
  None None None None
A None None None None
T None None None None

Prepare the dynamic programming matrix

Now that you can create a matrix with the correct dimensions, write a function that fills the top row and left column with multiples of the gap score. E.g., if the gap score is -2, you want the matrix to look something like this when you print it with print_dp_matrix:

          G    A    T
     0   -2   -4   -6
A   -2 None None None
T   -4 None None None

Write a function, prepare_dp_matrix, which takes three arguments:

  1. An integer (which represents the length of sequence one plus one)
  2. An integer (which represents the length of sequence two plus one)
  3. An integer, which represents the gap_score used for alignment.

The function must return:

  • A list of lists. The number of sub-lists must be equal to the first integer argument. The values in the first sub-list must be multiples of the gap score (the third argument). The first elements of the remaining sub-lists must be multiples of the gap score. All remaining elements of sub-lists must be None.

Example usage:

prepare_dp_matrix(3, 4, -2)

must return:

[[0, -2, -4, -6], [-2, None, None, None], [-4, None, None, None]]
NoteHint 1

You can call empty_matrix inside prepare_dp_matrix to get an empty matrix to fill in. Remember, the matrix needs as many rows as we can align bases from sequence one. Since that includes zero aligned bases, the number of rows must be equal to the length of sequence one plus one. The same logic goes for sequence two and the columns.

dp_matrix = empty_matrix(len(seq1)+1, len(seq2)+1)
NoteHint 2

When you have a matrix filled with None values, all you need to do is replace the right None values with multiples of the gap score. For example, the third element in the first sub-list is dp_matrix[2][0], which you would assign as 2 times the gap score. Similarly, dp_matrix[3][0] should be 3 times the gap score. So you need to figure out which elements to replace and which index pairs you need to access. Then, use range to generate those indices and for-loops to loop over them.

Prepare the traceback matrix

When we fill in the dynamic programming matrix, each score is computed from one of the three cells surrounding it left to top. To do the traceback at the end, we must record which one we used. I.e., if the traceback needs to go “up”, “left”, or to the “diagonal” cell. The traceback matrix has the same shape as the dynamic programming matrix and should end up with each cell filled with U for “up”, L for “left”, or “D” for diagonal. You need to prepare this matrix by filling the same rows as you did when preparing the dynamic programming matrix (except for the top-left one) like this:

          A    T
  None    L    L
G    U None None
A    U None None
T    U None None

Write a function, prepare_traceback_matrix, which takes two arguments:

  1. An integer (which represents the length of sequence one plus one)
  2. An integer (which represents the length of sequence two plus one)

The function must return:

  • A list of lists. The number of sub-lists must be equal to the first integer argument. In the first sub-list, all but the first value must be 'L'. The first values of the remaining sub-lists must all be 'U'. All remaining elements of sub-lists must be None.

Example usage:

prepare_traceback_matrix(3, 4)

must return:

[[0, 'L', 'L', 'L'], ['U', None, None, None], ['U', None, None, None]]
NoteHint 1

You can call empty_matrix inside prepare_traceback_matrix to get an empty matrix to fill in. Remember, the matrix needs as many rows as we can align bases from sequence one. Since that includes zero aligned bases, the number of rows must be equal to the length of sequence one plus one. The same logic goes for sequence two and the columns.

dp_matrix = empty_matrix(len(seq1)+1, len(seq2)+1)

Fill the matrices

Now that we can fill the top row and left column of our matrices, we can start thinking about how to fill them in completely.

For that, we need a score matrix of match scores. In Python, that is most easily represented as a dictionary of dictionaries like this:

score_matrix = {'A': {'A': 2, 'T': 0, 'G': 0, 'C': 0},
                'T': {'A': 0, 'T': 2, 'G': 0, 'C': 0},
                'G': {'A': 0, 'T': 0, 'G': 2, 'C': 0},
                'C': {'A': 0, 'T': 0, 'G': 0, 'C': 2}}

That lets you get the score for matching an A with a T like this: score_matrix['A']['T']. Note that match scores apply only to uppercase letters (A, T, G, C).

Write a function, fill_matrices, which takes four arguments:

  1. A string, which represents the first sequence.
  2. A string, which represents the second sequence.
  3. A dictionary of dictionaries like the one shown above, which represents match scores.
  4. An integer, which represents the gap score.

The function must return:

  • A tuple of two values. The first must be a list of lists of numeric values representing the filled-in dynamic programming matrix. The second must be a list of lists representing the filled-in traceback matrix.

Example usage: If score_matrix is defined as above, then

fill_matrices("GTC", "GC", score_matrix, -2)

must return:

([[0, -2, -4], [-2, 0, -2], [-4, 0, 0], [-6, -2, 2]],
 [[None, 'L', 'L'], ['U', 'D', 'D'], ['U', 'D', 'D'], ['U', 'U', 'D']])

When printed with print_matrix, the first should look like this:

      G  A  T
   0 -2 -4 -6
A -2  0  0 -2
T -4 -2  0  2

and the second should look like this:

          A    T
  None    L    L
G    U    D    D
A    U    D    D
T    U    U    D
NoteHint 1

You can call prepare_dp_matrix and prepare_traceback_matrix inside fill_matrices to get the matrices with the top rows and left columns filled in. Assuming seq1 is sequence one and seq2 is sequence two, then you can do it like this:

dp_matrix = prepare_dp_matrix(len(seq1)+1, len(seq2)+1, gap_score)
traceback_matrix = prepare_traceback_matrix(len(seq1)+1, len(seq2)+1)
NoteHint 2

To fill in the rest of the cells in each matrix, you need two nested for-loops to produce the indices of the i,j elements in the cells to fill in:

for i in range(1, len(seq1)+1):
    for j in range(1, len(seq2)+1):
        ...

Each combination of i and j lets you access an element dp_matrix[i][j] in dp_matrix or assign a value to it.

NoteHint 3

The value to assign to each dp_matrix[i][j] is the maximum of three values:

  1. The value of the cell to the left plus the gap score: left = dp_matrix[i][j-1] + gap_score.
  2. The value of the cell above plus the gap score: up = dp_matrix[i-1][j] + gap_score.
  3. The value of the diagonal cell plus the score aligning the base with index i-1 in sequence one (base1 = seq1[i-1]) with the base with index j-1 in sequence two (base2 = seq2[j-1]): diag = dp_matrix[i-1][j-1] + score_matrix[base1][base2].

I.e., max_score = max(left, up, diag)

NoteHint 4

If you have defined left, up, diag, and max_score inside the for loop as in Hint 3, and assigned max_score to dp_matrix[i][j] all that remains is to also fill in the corresponding cell, tb_matrix[i][j], in the traceback matrix. It should be 'D' if max_score == diag, 'U' if max_score == up, and 'L' otherwise.

Traceback

Write a function, traceback, which takes four arguments:

  1. A string, which represents the first sequence.
  2. A string, which represents the second sequence.
  3. A list of lists, which represents a traceback matrix.

The function must return:

  • A tuple of two strings that together represent the alignment of the sequences given as arguments one and two as specified by the traceback matrix.

Example usage: If traceback is defined as above, then

traceback_matrix = [
    [None, 'L', 'L', 'L'],
    ['U', 'D', 'D', 'L'],
    ['U', 'D', 'D', 'D'],
    ['U', 'U', 'D', 'L']
    ]
traceback('ATA', 'TAG', traceback_matrix)

must return:

('ATA-', '-TAG')

This is a difficult one. Give it a shot, but don’t despair. You can see an explained solution in the reveal below:

NoteThe traceback function 
def traceback(seq1, seq2, tb_matrix):
    aln1, aln2 = '', ''                        # Strings we will extend backwards.
    row, col = len(seq1), len(seq2)            # Start with last row and col.
    while row > 0 and col > 0:                 # While not at upper or left matrix edge.
        c1, c2 = '-', '-'                      # We let the two chars default to gaps.
        if tb_matrix[row][col] in ['U', 'D']:  # Came from row above.
            c1 = seq1[row-1]                   # A base from seq1 is aligned.
            row = row - 1                      # Next cell is in row above..
        if tb_matrix[row][col] in ['L', 'D']:  # Came from col to the left.
            c2 = seq2[col-1]                   # A base from seq2 is aligned.
            col = col - 1                      # Next cell is in col to the left.
        aln1 = c1 + aln1                       # Add symbol to from of aln1.
        aln2 = c2 + aln2                       # Add symbol to from of aln1.
    while row > 0:                             # At left edge of matrix.
        aln1 = seq1[row-1] + aln1              # A base from seq1 is aligned.
        aln2 = '-' + aln2                      # No base from seq2 is aligned.
        row = row - 1                          # Move up along the left matrix edge.
    while col > 0:                             # At upper edge of matrix.
        aln1 = '-' + aln1                      # No base from seq2 is aligned.
        aln2 = seq2[col-1] + aln2              # A base from seq2 is aligned.
        col = col - 1                          # Move left along the upper matrix edge.
    return aln1, aln2

The final alignment

Now you can write a function that performs the alignment. You get to do that yourself. It just calls fill_matrix and then trace_back to get the optimal alignment

Write a function, align, that takes four arguments:

  1. A string, which represents sequence one.
  2. A string, which represents sequence two.
  3. A dictionary of dictionaries, which represents the match scores (as described above).
  4. An integer, which represents the gap score.

The function must return:

  • A list of length two. The first element must be a string representing aligned sequence one. The second element must be a string representing the aligned sequence two.

Example usage:

align('ATAT', 'GATGAT', score_matrix, -2)

must return:

['-AT-AT', 'GATGAT']

Once you have written that function, you can print your alignment like this:

score_matrix = {'A': {'A': 2, 'T': 0, 'G': 0, 'C': 0},
                'T': {'A': 0, 'T': 2, 'G': 0, 'C': 0},
                'G': {'A': 0, 'T': 0, 'G': 2, 'C': 0},
                'C': {'A': 0, 'T': 0, 'G': 0, 'C': 2}}

aln1, aln2 = align('ATAT', 'GATGAT', score_matrix, -2)
print(aln1)
print(aln2)

Now you can write a function that performs the alignment. You get to do that yourself. It just calls fill_matrix and then trace_back to get the optimal alignment

Write a function, align, that takes four arguments:

  1. A string, which represents sequence one.
  2. A string, which represents sequence two.
  3. A dictionary of dictionaries, which represents the match scores (as described above).
  4. An integer, which represents the gap score.

The function must return:

  • A list of length two. The first element must be a string representing the first aligned sequence. The second element must be a string representing the second aligned sequence.

Example usage:

score_matrix = {'A': {'A': 2, 'T': 0, 'G': 0, 'C': 0},
                'T': {'A': 0, 'T': 2, 'G': 0, 'C': 0},
                'G': {'A': 0, 'T': 0, 'G': 2, 'C': 0},
                'C': {'A': 0, 'T': 0, 'G': 0, 'C': 2}}
align('AATACGTG', 'AAGACGGTGCAT', score_matrix, -1)

must return:

('AATAC-GTG---', 'AAGACGGTGCAT')

Now you can compute an alignment like this:

aln1, aln2 = align('AATACGTG', 'AAGACGGTGCAT', score_matrix, -1)
print(aln1)
print(aln2)

Write a function, identity_line, that takes two arguments:

  1. A string, which represents the first aligned sequence.
  2. A string, which represents the aligned sequence two.

The function must return:

  • A string with '|' characters at indices where the two string arguments are the same and ' ' (space) characters where they differ.

Example usage:

identity_line('AATAC-GTG---', 'AAGACGGTGCAT')

must return:

'|| || |||   '
